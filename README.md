# calc-ai
One simple calculator using neutral network to operate calculations such as addition, subtraction, multiplication and division. 
The beauty here is that the two input digits must be drawn by the user.

# php pre-traing
The php training script will download the MNIST hand writing patterns for numeric digits

# JS front-end
The front end has two simple canvas to draw a digit and an operation picker.
The calculation will run a trained neural network with the MNIST patterns
